# 智谱 GLM 凭据申请

GLM 用于把 Claude 的长回复**压缩**成口播句。比如 500 字的方案说明 → 50 字的"做了什么"摘要。

**这是可选的**——不填 GLM key，长文本会被硬截断到前 120 字。

## 步骤

1. 注册并登录 [智谱 AI 开放平台](https://open.bigmodel.cn/)
2. 进入 [API 密钥](https://open.bigmodel.cn/usercenter/apikeys)
3. 创建一个新 API Key，复制 Bearer 字符串
4. 填到 Claude Code Voice 的 **凭据** 标签页

## 模型选择

| 模型 | 速度 | 价格 | 适合 |
|------|------|------|------|
| `glm-4-flash` | 最快（~1s） | **免费** | 默认推荐 |
| `glm-4-air`   | 快      | 便宜  | 想要更准的压缩 |
| `glm-4-plus`  | 较慢    | 贵    | 对压缩质量要求高 |

口播压缩任务很简单（删客套话、保留实词），`glm-4-flash` 完全够用。

## 失败回退

GLM 调用超时/失败时（默认 5 秒超时），脚本会回退到把原文硬截断到 120 字直接合成——保证你**总能听到一些东西**，不会因为 GLM 掉线而完全静音。
